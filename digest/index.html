🔧Platform & API
June 9, 2026
Claude Fable 5 (claude-fable-5) and Claude Mythos 5 (claude-mythos-5) launched — Both support a 1M token context window, 128k max output tokens, and always-on adaptive thinking. Mythos 5 is currently limited to Project Glasswing participants.
June 9, 2026
New tokenizer (30% more tokens) — Fable 5 and Mythos 5 use the tokenizer introduced with Opus 4.7. The same text now produces roughly 30% more tokens versus pre-Opus-4.7 models. Use the token counting API with model: "claude-fable-5" to re-measure your prompts.
June 9, 2026
New stop_reason: "refusal" — When Fable 5's safety classifiers decline a request, the Messages API now returns this new stop reason. Requests refused before any output is generated are not billed. An opt-in fallbacks parameter (beta) can re-run refused requests on another model automatically.
June 9, 2026
Rate limit increases — Anthropic doubled Claude Code rate limits and raised API limits for Opus to support developers and enterprises building at larger scale.
