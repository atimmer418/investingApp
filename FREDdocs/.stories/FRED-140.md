## Summary
Define the structure and conversion strategy for the FRED landing page (fredvested.com). Two entry points: mobile visitors see a streamlined App Store download CTA; desktop/web visitors go through an interactive quiz or email capture flow before being directed to download. This is a strategy and copywriting deliverable — no app code involved.

## Acceptance Criteria
1. Define the two-path experience:
   - **Mobile visitors**: hero + value prop + single "Download on App Store" CTA. No quiz, minimal friction.
   - **Desktop/web visitors**: short interactive quiz (3–5 questions, e.g. "What's your biggest financial goal?") that ends with personalized hook + email capture form. Email collected → drip sequence begins.
2. Write the quiz questions and answer options for the desktop funnel (3–5 questions max).
3. Write the hero headline, sub-headline, and primary CTA copy for both paths.
4. Decide on email platform for the capture form (Mailchimp, ConvertKit, Beehiiv, etc.) and note it in this ticket.
5. Sketch or wireframe the page layout — can be rough ASCII, Figma frame, or Canva mockup.
6. Note any legal copy requirements (e.g. SEC/FINRA disclaimers, privacy policy link) that must appear on the page before publishing.
