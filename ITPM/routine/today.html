FRED-116 — Review Prompt After First MFU — Select Approach
Option A Recommended
@capacitor/rate-app — Native iOS Sheet
Install the official Capacitor rate-app plugin. In the MFU modal's dismiss callback, check localStorage for 'hasSeenFirstMFU'. If absent, call RateApp.requestReview() and set the flag. Fires the native iOS star-rating sheet — no custom UI. Apple throttles display frequency, so worst case is the sheet doesn't show; there is no downside.
Risk: Low
Est: 1h
Pros: Official plugin, zero custom UI, fires at peak satisfaction moment
Option B
Custom Pre-Prompt Modal ("Enjoying FRED?")
Show a custom "Enjoying FRED? Yes / Not Yet" modal before invoking the native sheet. On "Yes" → native sheet. On "Not Yet" → offer a feedback form. More control over timing but adds UI complexity and a friction step before the rating.
Risk: Low
Est: 3h
Cons: Adds friction, custom UI to maintain, Apple guidelines discourage pre-prompts
Option C
Defer to Post-Launch with Server-Side Timing
Skip now, implement post-launch with a backend flag that controls when the prompt fires, enabling A/B testing of timing and frequency.
Risk: Low
Est: Future
Cons: Delays a high-value retention action with no good reason to wait
Triage Findings
FRED-124 — Change Bank Account Page Full UI Overhaul
In Scope
  • Complete visual redesign of the change-bank-account settings page to match Account Security card standard
  • Display current linked bank name and masked account number in a detail card
  • Single "Change" CTA that triggers the existing Plaid Link flow
  • Loading state: spinner while fetching current bank info from backend
  • Empty state: "No bank account linked" with a "Link Bank" CTA
  • Error state: toast if Plaid Link fails or returns an error
  • Success state: toast confirmation on successful bank switch
  • Mobile-first layout verified at 390×844
Potentially Out of Scope
  • Plaid backend integration changes — already in place
  • Multiple bank account support — not planned for Piggy Tier
  • Bank logo/branding assets — not available yet (use institution name as text)
  • Transaction history on this page — belongs on a separate screen
UX Considerations
  • Loading: full-screen semi-transparent veil while bank data loads (consistent with rest of app)
  • Empty: prominent "Link Bank Account" CTA card — don't leave a blank page
  • Error/retry: toast with "Try again" action; Plaid Link errors should not crash silently
  • Mobile-first: generous card padding, tap targets ≥ 44px, no horizontal scroll
  • Tier gating: bank connection is Piggy Tier — no gate needed
FRED-116 — Prompt Users for Review After First MFU
In Scope
  • Install @capacitor/rate-app if not already present
  • Add import and call to RateApp.requestReview() in the MFU modal dismiss handler
  • Guard with localStorage.getItem('hasSeenFirstMFU') — fires exactly once per install
  • Set localStorage.setItem('hasSeenFirstMFU', 'true') immediately after triggering
  • Prompt fires after modalController.dismiss() completes — does not block or delay the close
Potentially Out of Scope
  • Android review prompt — future story, @capacitor/rate-app has an Android path but save for after iOS launch
  • Tracking whether user actually submitted a rating — iOS doesn't expose this
  • Custom review UI — native sheet only per Apple guidelines
UX Considerations
  • Native Apple sheet only — no custom loading states or animations needed
  • Fires post-dismiss so the MFU experience is uninterrupted
  • Apple may throttle display (shows at most 3 times per year per device) — this is expected behavior, not a bug
Potentially Out of Scope
  • FRED-188 (null userId guard in ChatService) — 15-minute fix that can be folded in as a bonus; not a planned priority but worth doing if there's time after FRED-116
  • FRED-109 (investment question wording) — Easy and valuable but deferred to tomorrow; doing three stories today risks none shipping polished
  • Bank branding logos (FRED-124) — Deferred; use institution name as text only, no logo fetch needed this sprint
  • Multiple bank account support — Not in scope for Piggy Tier; out of scope for today and this phase
